# 声音验收与交接

## 状态链

```text
目标/消费者已确认 → 代表样稿已试听 → 文件已检查 →
SoundDef 契约已交接 → 已绑定 → 游戏内事件已验证 → 听感已接受
```

每个状态分别留证据：

- **目标/消费者**：事件、材质、方向/位置、时长、one-shot/loop。
- **样稿**：实际可播放文件、试听方法、用户反馈和保留/修改项。
- **文件**：路径、哈希、容器、采样率、声道、位深、时长、峰值/响度、循环检查。
- **契约**：clip path、SoundDef、context、sustain、优先级、随机变体、音量范围。
- **绑定**：触发入口、目标位置、暂停/速度/销毁/取消行为。
- **游戏验证**：短程/远程、单次/重复、不同游戏速度、镜头距离、加载或存档相关场景。

## 游戏内检查

- 声音是否只在预期事件播放。
- 时长是否与动画阶段匹配。
- 循环是否连续，结束是否干净。
- 音量是否相对其它枪声、机械音和 UI 声合理。
- 重复播放是否刺耳、低频堆积或发生自相掩蔽。
- 取消、脱图、暂停和销毁是否停止/恢复正确。

缺少目标版本游戏实测时提供明确复现步骤并标为未验证。不得把 WAV 可播放、静态 SoundDef 存在或一次系统音频播放写成完整游戏验收。
