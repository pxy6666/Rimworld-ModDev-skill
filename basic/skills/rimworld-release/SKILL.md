# RimWorld 发行准备

依据工程实际目录和用户发行目标工作。打包与测试要点见 [package.md](references/package.md)。发行准备可以连续完成；不要推断它自动授权上传。

首次或构建/打包工具缺失时按项目 rimworld-setup 准备必要组件；只打包纯 XML 不要求安装全部 C# 检索工具，已有有效验证可复用。

1. 确认支持版本、必要/可选 DLC 和上游、当前构建及测试证据。
2. 运行相关检查与构建；从规定输入生成干净目录，核对 XML、加载文件、素材和自己的 DLL。
3. 核对 About、依赖、语言、许可/署名、描述与实际玩法；不擅自决定冲突数值。
4. 生成包、文件清单与验证状态。排除源码参考、日志、索引、本机配置和游戏/框架程序集。
5. 用户要求上传时使用可用发布能力，确认具体目标与实际授权；否则交付本地产物。

现有静态/编译证据可以复用，变动后失效相关项。游戏未测不能标为可用性已验证。完整 mod 的可调参数、存档身份和依赖不在发行整理中无故改动。

本项目 `tools/mod.ps1 package` 使用新目录与最新构建记录，默认不安装到游戏、不上传工坊。CLI 不证明所有兼容组合正确。
