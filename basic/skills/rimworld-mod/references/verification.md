# 按成品验收

| 内容 | 必选 | 相关条件成立时增加 |
| --- | --- | --- |
| 数据补丁 | 输入目标/补丁语法、最终值与相关行为 | 上游/DLC 加载、受影响旧档 |
| 图片/声音/文案 | 路径/键、实际显示或播放、与目标一致 | 涉及 XML 则查引用；方向/材质/占位符按资源种类 |
| 新 XML 内容 | 模板、引用、获取和使用、资源 | 状态/旧实例/DLC/上游组合 |
| C# 功能 | 编译、实际入口、适用的 XML 挂载、逻辑边界与行为 | 存状态必测存取；高频逻辑查性能；全局补丁查范围 |
| 系统/显示功能 | 注册与触发时机、数据语义、对象范围、配置和清理 | 仅显示时核对结算不变；密集事件/重复提示、缩放/暂停、地图与旧档生命周期 |
| 可选上游 | 有/无上游的加载与功能 | DLL 引用隔离、相关冲突组合 |
| 完整功能 mod | 组成模块检查、入口与组合行为、文件完整 | 依机制选择存档/视觉/性能/兼容 |
| 发行包 | 上述实际证据、干净文件、依赖/版本/许可 | 用户要求上传时再做发布 |

检查结果分为通过、失败、未验证、不适用。未跑游戏不能写加载/行为通过；缺素材不能当资源检查通过。CLI 静态检查不执行完整游戏加载器。

资源验收按 assets.md 的清单核对必要文件或运行时提供方、文案变量与实际配置。原型占位、收到文件和已验证资源分开报告；正式成品不能悄悄保留未满足要求的占位。用户未提供自有图形但已采用有效的原版/上游引用，不视为缺素材。

执行只对具体剩余风险有意义的复验；编译或静态检查通过后按功能测试，不无限重复同一检查。

对比修改前的文件/元数据基线，检查新增/修改/删除；作用范围和玩法符合度需人工或模型语义审查。证据失效与新修改关联，不能用旧日志证明新 DLL 正确。
