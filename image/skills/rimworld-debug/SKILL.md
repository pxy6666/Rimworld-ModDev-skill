# RimWorld 排错路由

恢复相关记录和实际日志/产物，先明确目标版本；当前安装不是错误会话的版本证明。

- 1.6：读 [1.6 排错](../rimworld-16-debug/SKILL.md)。
- 1.7：读 [1.7 排错](../rimworld-17-debug/SKILL.md)。
- 给已有 1.6 工程增加 1.7：读 [迁移](../rimworld-17-migrate/SKILL.md)。
- 双版本：各自取来源与会话，执行唯一 [排错过程](references/debug-workflow.md)；相关生命周期/存档按实际功能验证。

目标未知先澄清，独立调查可继续。多个独立调查/修复块按 [并行分工](../rimworld-mod/references/parallel-work.md) 使用可用且获授权的子 agent。已确认计划和缺项随阶段交接，不重新审批同一方案。
