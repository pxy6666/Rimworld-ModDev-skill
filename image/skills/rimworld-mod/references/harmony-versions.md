# Harmony：按实际版本选择

仅在功能确需补丁时读取；库调用 Harmony API 不等于给 Harmony 打补丁。先核对目标的提供方、加载目录、程序集版本/哈希，再进入 [Harmony 2](harmony-2.md) 或 [Harmony 3](harmony-3.md)。画像中的已安装版本是基线，不是所有用户必须使用的固定版本。

公共契约：目标的真实 owner/重载/泛型/ref/out/静态性、目的、时机、范围、依赖与消费者。检查 __instance、__result、参数及 ___字段 的实际可赋值类型，不靠同名类型或反射字符串判断。补丁初始化失败要保留首个内部异常，排查后续重复执行和半初始化状态；不靠吞异常或压日志修复。

Prefix/Postfix 由时机选，多项必要补丁可共存；Transpiler 必须说明稳定扩展点或更局部方式不足的原因。绑定/编译成功只证明相应层，仍需首次、重复和相关生命周期场景。跨版本补丁不得复用未证实的生成方法、token 或 IL 布局。

签名小查询使用当前技能 `scripts/catalog.py query --target 1.6 --purpose harmony --limit 5`；1.7 对应换目标。查询未收录/默认值未解析时查真实 DLL，不能用邻近版本规则补结论。
