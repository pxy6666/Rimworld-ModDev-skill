# 配置契约、检索与真正缺项

用途与真实类型确认后读取。契约说明本功能需要哪些配置、谁读取、值从哪来、何时生效；不能把全部可用字段抄成必填表。

## 查证快速路径

1. 复用来源、构建和条件匹配的功能记录；家具/设施/种植等按需查 [机制笔记](mechanics.md)。
2. 按 [本地查证命令](local-lookup.md) 核对游戏身份，批量查原始 Def 和 ParentName 候选；纯 XML 不要求准备编译环境或反编译。
3. 批量查类型、签名和静态引用；需要实现语义才读同哈希的源码缓存。短名/重载歧义先消歧，不以目录时间推断版本。
4. 已验证来源且适合问题的 MCP/桥接可替代相关步骤。原始 XML、元数据、方法体与运行时合并 Def 分开取证；未接通不阻塞本地查询。
5. 保存有关来源、签名/配置、结论和缺口。关键接口未证实则暂停依赖部分；新 Def 不要求预先存在。

反编译只查相关配置/方法，优先签名和消费者。私有配置字段、自定义解析、XML 别名、构造默认也可能有效；属性/计算输出不自动可填 XML。继承、补丁与引用能解析不等于行为成立；保留读取依据，不复制整类游戏逻辑。

## 要求状态与值来源分开

配置表至少列根类型/实际 Class、嵌套路径或接口、功能条件、状态、有效值/单位、来源、读取者、依据及验证，见 [feature.md](feature.md)。

| 要求状态 | 判断与处理 |
| --- | --- |
| 功能必需 | 缺有效配置则目标无法成立；合法且满足目标的继承/默认也可满足，不一定显式写入 |
| 条件必需 | 只在所选用途、行为类/组件或条件启用时需要；注明条件 |
| 已核实继承/合法默认 | 保存来源与效果，可省重复项；不符合当前玩法仍需选择覆盖值 |
| 可选/不适用 | 不为了齐全或高频而填；选择启用时再核对条件 |
| 技术未确认 | 查字段、默认/合并规则、引用与消费点，不转成玩家数值选项 |

| 值来源 | 保存依据 |
| --- | --- |
| 用户指定 | 原要求/选择和最终值；明确且合法的 `0`/`false`/空集合不算缺项 |
| 模板/默认 | 身份、继承/构造/解析依据、版本及是否满足目标 |
| 授权 CLI 决定 | 授权范围、同用途参照、选择理由、最终值 |
| 临时占位 | 用户接受的原型范围、替换责任及正式完成前缺项 |
| 未定 | 所需决定/证据；仅阻塞依赖它的步骤 |

默认值合法与适合本功能分开判断。Def 引用需核对目标类型、提供方、加载条件和实际身份，不能用相似名字替代缺失定义。

## 玩家决定什么

核对明确值和继承/默认后，将真正未定的玩法数值、资源或获取规则按 [workflow.md](workflow.md) 的三种模式处理。内部字段、枚举、类名、引用键和技术路径由代理查证；有结果差异时解释给玩家。

CLI 决定以同用途、匹配版本的原版/已选上游为参照，考虑关联值并保存依据，不发明字段或覆盖明确值。用户控制可合并伤害/射速/射程等相关选项，不逐条问所有 XML。“全权决定”不能把未证实接口变成事实。

## 频率表怎样使用

按真实类型、用途、路径和 Class 查询小量结果，只用于优先检查和找模板。区分原始出现、继承推断、条件加载候选、运行时证据，保留分母与版本。

以下是开发工程的可选工具示例，技能包不附带统计脚本、报告或本机数据库。目标工程或已知父工具工作区提供时，用显式路径查看 `tools/def_catalog.py query --help`、`tools/workshop_stats.py query --help`；核对实际数据构建，1.6 统计不证明 1.7 契约。

上述工具常用 `docs/def-reference/` 候选字段表和 `docs/workshop-reference/` 工坊表。实际存在时可用 Python 执行 `tools/def_catalog.py query --type ProjectileProperties --field armorPenetrationBase --limit 5` 或 `tools/workshop_stats.py query --profile ThingDef/plant --field tickerType --limit 5`；结果按其证据级别判断，不为一项让模型读整份大 JSON。

高频不等于必填、低频/零频不等于无效。模板常省略项可能实际必需；自定义消费者有表外字段。统计不能证明默认值、合法范围或运行行为时保留未验证项。
